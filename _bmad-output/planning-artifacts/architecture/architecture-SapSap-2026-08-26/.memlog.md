- (decision) AD-1 Paradigm & Stack: Modular Monolith API REST backend built with Laravel (PHP 8.3+) and PostgreSQL database.
- (decision) AD-2 Frontend Stack: Angular 18+ web applications for Business (business.sapsap.bf) and Admin (admin.sapsap.bf), sharing code conventions with the Ionic/Capacitor Angular mobile app.
- (decision) AD-3 Database & ORM: PostgreSQL with Eloquent ORM and PostGIS spatial extensions for geolocation queries.
- (decision) AD-4 Mobile Network Resilience Strategy: Online-first submission model with in-memory retry mechanism. Form state and compressed photos remain preserved in transient UI state if network drops during submit; user can retry transmission without data loss.
- (decision) AD-5 Mobile Hardware Enforcement: @capacitor/camera constrained strictly to CameraSource.Camera (gallery blocked). Client-side image compression (JPEG 80%, max 1920x1080) applied prior to upload. @capacitor/geolocation captures GPS coordinates enforced by backend PostGIS Haversine calculation (<100m).
- (decision) AD-6 Payment & Payout Driver Architecture: Interface-driven Mock Payment Gateway (PaymentGatewayInterface with SimulatedPaymentDriver). Enables full simulation of Orange Money and Moov Money deposits and withdrawals for MVP testing without real provider API credentials. Pluggable design allows switching to production aggregator drivers seamlessly.
- (decision) AD-7 Wallet & Accounting Ledger: Immutable Double-Entry Ledger (wallet_transactions table) recording balance shifts (pending, available, total_earned), transaction types (campaign_deposit, escrow_lock, reward_credit, withdrawal_request), and status flags.
- (decision) AD-8 Authentication & RBAC: Laravel Sanctum token authentication for Capacitor mobile app (Phone + OTP) and Angular Web apps (Email/Password). Spatie Laravel-Permission for RBAC roles (super-admin, validator, company-admin, company-viewer).
- (decision) AD-9 Media Storage & Anti-Fraud Hash: Local disk storage (storage/app/public/submissions/) with SHA-256 image fingerprinting upon upload. Rejection of duplicate photo hashes across missions.
- (decision) AD-10 Automated 48h Auto-Validation Scheduler: Laravel Scheduler executing CheckPendingSubmissionsJob hourly to automatically approve submissions pending over 48 hours and release wallet escrow funds.
